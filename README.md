# 🎬 Explainable Hybrid Movie Recommendation System

An intelligent and explainable movie recommendation system developed using **Python, Flask, NLP, FAISS, and TMDB API**. The system provides personalized movie suggestions based on user preferences, semantic similarity, and mood-aware recommendations while offering explainable insights into why a movie was recommended.

---

## 📌 Project Overview

Traditional recommendation systems often act as black boxes, making it difficult for users to understand why certain movies are suggested. This project addresses that challenge by combining hybrid recommendation techniques with explainable AI to deliver transparent and personalized recommendations.

The system analyzes movie metadata, genres, descriptions, user interests, and semantic relationships to recommend relevant movies with explanations and OTT platform availability.

## 🏗️ System Workflow

1. Collect movie metadata from TMDB API.
2. Clean and preprocess movie data.
3. Extract important features such as:
   - Genres
   - Overview
   - Keywords
   - Ratings
   - Popularity
4. Generate embeddings using NLP techniques.
5. Store embeddings in FAISS vector database.
6. Perform semantic similarity search.
7. Apply hybrid recommendation logic.
8. Generate explainable recommendations.
9. Display personalized results through Flask web application.
